## How this track is maintained

- Each topic folder contains one `.py` file with that topic's code, preserved exactly as written during practice.
- Mistakes, incomplete programs, and commented-out experiments are kept intentionally.
- No syntax is corrected and no logic is altered.
- Personal information (if any) has been replaced with fake placeholder values and flagged with a `[PRIVACY: ...]` comment.
- New Bro Code-related practice is added to the appropriate topic folder. If it's a new topic, create a new folder (lowercase snake_case) with a `.py` file inside.
- The topic table above is updated when a new topic folder is added.

## How to use

Each file contains practice snippets, many commented out or incomplete. Uncomment the section you want to try and run it individually. Do not run the entire file as one program.
