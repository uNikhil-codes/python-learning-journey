# 100-Problems Python Practice

This folder contains my personal Python problem-solving practice.

The problems are divided into different levels and topics. The file `100_problems.py` contains:

- Problem statements.
- My own attempts.
- Experimental solutions.
- Incomplete solutions.
- Different approaches to solving problems.
- Learning notes and comments.

## Important notes

- My solutions may be **incomplete or experimental**.
- The file preserves my **actual attempts** — it is not presented as fully solved.
- Some problem numbers are missing, and not every solution is complete.
- Problems are **not** marked as completed unless that status has been explicitly verified.
- No fake completion statistics are generated.

## How this file is maintained

- The file is preserved exactly as written — mistakes, incomplete programs, and commented-out experiments are kept intentionally.
- No syntax is corrected and no logic is altered.
- More problems and solutions will be added as I progress.

## How to use

Open `100_problems.py` and work through individual problems or attempts as needed.
